# خدمة التصيير والمساعد الذكي — cuisine render-service

خدمة صغيرة (Python بلا مكتبات خارجية + Blender) تستقبل هندسة التصميم من التطبيق (`src/math/renderScene.ts`:
كل صندوق وواجهة وسطح عمل وقطعة مكتبة بأماكنها الحقيقية) وتعيد صور **Blender Cycles** فوتوريالية —
نفس المقاسات والأماكن تمامًا، لأن التطبيق هو مصدر الحقيقة والخدمة ترسم فقط.

## التشغيل — أربع طرق (اختر ما يناسبك)

### 1) على جهازك (الأسهل للتجربة)
```bash
# ثبّت Blender 4.x وأضفه إلى PATH، ثم:
cd render-service
TEXTURES_DIR=../public/textures python3 server.py        # Windows: set TEXTURES_DIR=..\public\textures && python server.py
```
### 2) Docker (وحدة معالجة مركزية)
```bash
docker build -t cuisine-render render-service/
docker run -p 8787:8787 -e TEXTURES_DIR=/tex -v /path/to/project/public/textures:/tex cuisine-render
```
### 3) GPU سحابي (RunPod / Vast.ai — للنهائي 4K السريع)
- أنشئ Pod بصورة Ubuntu 22.04/24.04 مع GPU، افتح المنفذ 8787.
- `apt-get install -y blender python3` ثم انسخ هذا المجلد وشغّل `server.py` كما في (1).
- على GPU تتحول دقائق الـCPU إلى ثوانٍ (CUDA/OptiX يُكتشفان تلقائيًا).

### 4) خادمك الخاص (VPS)
كما في (3)، ويُفضّل وضعها خلف نفق/VPN — الخدمة بلا مصادقة، لا تنشرها عارية على الإنترنت.

## في التطبيق
في صالة العرض: **🎬 تصيير سينمائي** ← ضع عنوان الخدمة (افتراضيًا `http://localhost:8787`، يُحفظ في المتصفح)
← *معاينة سريعة 720p* أو *نهائي 4K (٣ زوايا)* ← **صيّر الآن**.
و**🧠 تدقيق ذكي** يعرض فحصًا تقنيًا حتميًا فورًا، وإن ضبطت المفتاح يسأل المساعد الذكي عن تصميمك.

## المساعد الذكي (اختياري)
```bash
ANTHROPIC_API_KEY=sk-... COPILOT_MODEL=claude-sonnet-4-5 python3 server.py
```
المفتاح يعيش على الخادم فقط — لا يصل إلى المتصفح أبدًا. بدونه يعمل التصيير والتدقيق المحلي كاملين.

## ملاحظات صادقة
- الخامات: تلتقط الخدمة ملفات `public/textures` بنفس اتفاقية التطبيق (`wood_<brand>.webp`...) أو خامة المشهد المختارة؛ غياب الملف يعني لونًا مسطحًا لا صورة سوداء.
- سطح العمل يُرسم بلوح كامل لكل جدار (بلا قصّات الحوض/الموقد في هذه النسخة).
- زوايا الكاميرا الثلاث (hero/front/top) تأتي من التطبيق؛ النهائي يصيّرها كلها، والسريع الأولى فقط.
