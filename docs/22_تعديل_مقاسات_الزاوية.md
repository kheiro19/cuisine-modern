# 22 — تعديل مقاسات الزاوية L بعد بنائها (الذراعان والمربع)

> **الطلب:** «خزانة الزاوية: لا أستطيع تعديل عرض الذراعين — لماذا وضعتهما قياسيتين دائماً؟ وعندما زدت المقاس **انفصلت جهة الباب**.»
> **الحال:** الذراعان والمربع أرقامك أنت الآن، تُعدَّل في أي وقت وبأي مقاس داخل حدود المخزن، والصناديق الثلاثة تتحرّك **معاً**
> بخزنة واحدة (Undo واحد) — فلا يبقى فراغ عند جهة الباب.

## 1. لماذا كانا «قياسيين دائماً»؟

الزاوية تُبنى كثلاثة صناديق عادية تشترك في مجموعة واحدة: `SQUARE` (مربع) + `ARM_A` (ذراع الجدار الخلفي) + `ARM_B`
(ذراع الجدار الجانبي). مقاساتها تُحسب مرة واحدة عند الإضافة من `lCornerBoxes()`، ثم تُحفظ على كل صندوق.

في النموذج (`App.tsx`) كان مسار الحفظ يكتب عرض الذراع هكذا:

```ts
// قبل الإصلاح — بالعرض القديم، لا بالعرض الذي كتبه المستخدم
const corner = editing.cornerSide
  ? withCornerExtension({ ...editing, cornerFillerMm, cornerFillerSides }, resolved.zones, frontTh)
  : null;
const savedPatch = corner ? { ...patch, width: corner.width, ... } : patch;
//                                      ↑ corner.width = editing.width (العرض المحفوظ سابقاً)
```

أي أن الحقل `W` في النموذج كان **يُقرأ ثم يُهمَل**: كل حفظ يعيد كتابة العرض الأصلي. والصناديق الثلاثة لم تكن
تُقرأ معاً أبداً، فتغيير صندوق واحد لا يحرّك جاريه ⇒ إن استطاع المستخدم تكبير ذراع، ظهر فراغ بينه وبين المربع
عند جهة الباب.

## 2. ما صار الآن

### أ. لوحة «مقاسات الزاوية» في النموذج

عند فتح أي صندوق من الثلاثة تظهر لوحة بثلاثة أرقام، وكل رقم مقبول في أي وقت:

| الحقل | ماذا يعني | المدى |
|---|---|---|
| المربع | ضلع المربع = **عمق** كل صناديق الزاوية | 300–700 مم |
| الذراع الخلفي | عرض الذراع وبابه على الجدار الخلفي | 300–700 مم |
| الذراع الجانبي | عرض الذراع وبابه على الجدار الجانبي | 300–700 مم |

الحقل `W` أعلى النموذج هو **نفس الرقم** الخاص بالصندوق المفتوح (المربع ⇒ ضلعه، ذراع ⇒ عرضه)، فتعديل أحدهما
هو تعديل الآخر — لا رقمان يتناقضان. وتحت الحقول سطر حيّ يقرأ الامتداد الحقيقي:

```
يحتاج 1200 مم على الجدار الخلفي (المتاح 2400) و1050 مم على الجانبي (المتاح 1800).
المربع والذراعان صناديق ثلاثة تتحرك معاً بخزنة واحدة.
```

### ب. مسار الحفظ: حساب واحد للثلاثة (`math/lCorner.ts`)

أُضيفت ثلاث دوال صافية، مُختبَرة وحدها (9 اختبارات):

```ts
cornerDimsOf(cabs)                       // الصناديق الثلاثة ⇒ { wall, depthMm, armAMm, armBMm }
relayoutCornerGroup(cabs, dims, roomMm)  // الأرقام الثلاثة ⇒ عرض/عمق/موضع/جدار لكل صندوق
cornerFitsWalls(span, backMm, sideMm)    // هل تدخل الزاوية في الغرفتين؟
```

و`relayoutCornerGroup` تنادي **نفس** `lCornerBoxes()` التي بُنيت بها الزاوية أول مرة: قاعدةٌ واحدة، مستدعِيان —
فلا يمكن أن تختلف الزاوية المعدَّلة عن زاوية جديدة بنفس المقاسات.

في `App.tsx` صار الحفظ:

1. يقرأ الأرقام الثلاثة (من اللوحة + `W`/`D` للصندوق المفتوح، وهو الفاصل للأخير).
2. يرفض بأرقام صريحة إذا خرجت الزاوية عن الجدارين: «⛔ … تحتاج 1300 مم … لم يُغيَّر شيء».
3. يحسب المواضع الثلاثة، ثم يكتبها **بنداء واحد** عبر `patchCabinets` الجديدة في `FurnitureContext` — خزنة واحدة
   (Undo واحد)، ولا يمكن أن تُرى الزاوية نصفَ معدَّلة.
4. يعيد قراءة **قاعدة L الواحدة** (`cornerDeckOf`) من الصناديق كما ستكون، ويكتبها على الثلاثة.
5. يعيد حساب **ضلفة الزاوية الثابتة** على العرض الجديد — بنفس الجملة التي كانت تُعرض سابقاً، فلا يضيع أي رقم.

### ج. تفاصيل محفوظة بالتصميم

- **الفارق الذي يحمله الصندوق** (ضلفة ثابتة سابقة) يبقى فوق العرض الجديد: ذراع 469.5 (450 + 19.5) تصبح 619.5 عند
  زيادة 150 مم، لا 600.
- **جهة المفصلات والواجهة والأدراج** تُترك كما هي: الصناديق تتحرك، والضلفة تتوسّع مع ذراعها تلقائياً.
- **الزاوية اليمنى** تُقاس من طرف الجدار (المربع ثابت في آخره، والذراع ينمو نحوه) — مقاساتها لا تُقلب.
- **الزاوية العلوية** تُعدَّل بنفس الشريط (عمقها 350 مم مسموح: حدود الزاوية 300–700 لا حدود الخزانة الأرضية).

## 3. الأثر على بقية المحرّكات

| المحرّك | الأثر |
|---|---|
| BOM والقص | الصندوق يتغيّر عرضاً وموضعاً، فتُعاد كل قطعه وبابه — لا شيء يدوي |
| المخزون | `refresh` يعيد حساب السعر والحجز بعد الكتابة (كما كان) |
| قاعدة L | `cornerGroupDeckMm` يُعاد حسابه ويُكتب على الثلاثة ⇒ قطعة واحدة، قصّة واحدة |
| الدرج والرجوع | `withCornerExtension` يُعاد على العرض الجديد ⇒ الرجوع 100 مم يبقى في مكانه |
| 3D | المعاينة تتبع `resolved.width` كما كانت، والزاوية كاملة في صالة العرض |
