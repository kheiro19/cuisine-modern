## 1. الطلب

> «غسالة + أبواب فوقها: تُلغى القاعدة ✅ — لكن **لا تضع لوحاً تحت الجهاز الأرضي**، واللوح المحذوف من الرسم **لا يُحسب في القص ولا في الفوترة** لأنه غير موجود أصلاً.»

القاعدة القديمة كانت على مستوى **الخزانة**:

```ts
// قبل
const a = zones.length === 1 && zones[0].kind === 'APPLIANCE' ? zones[0].appliance : undefined;
```

أي: «البدن مفتوح» فقط إذا كان الجهاز **وحيداً** في الخزانة. بمجرّد إضافة أبواب فوق الغسالة، تعود الخزانة بدناً كاملاً: لوح قاع + ظهر كامل + **لوح فاصل محذوف** (خطأ آخر: القسم العلوي كان يبقى بلا شيء يسانده).

## 2. القاعدة الجديدة

القاعدة انتقلت إلى مستوى **القسم السفلي**:

```ts
// rules/appliances.ts
export function isFloorApplianceZone(z) {
  return !!z && z.kind === 'APPLIANCE' && !!z.appliance && OPEN_BAY_APPLIANCES.includes(z.appliance);
}

// math/zones.ts
export function isOpenCarcase(zones) { return isFloorApplianceZone(zones[0]); }
```

> **المعنى:** إذا كان أسفل الخزانة جهازاً يقف على الأرض، فالخزانة **بلا لوح قاع** — سواء كان الجهاز وحيداً أو تحته أدراج/أبواب/رفوف.

### ما تغيّر في الألواح

| اللوح | قبل (جهاز + قسم فوقه) | بعد |
|---|---|---|
| **Bottom Deck Panel** | يُقص ❌ | **لا يُقص ولا يُرسم ولا يُفوتر** ✅ |
| **Zone Divider Panel** | لا يُقص ❌ (القسم العلوي بلا سند) | **يُقص** ✅ |
| **Backwall Panel** | كامل الارتفاع (خلف الغسالة!) ❌ | **من أعلى التجويف فقط** ✅ — ولا يُقص إطلاقاً إن لم يكن فوقه شيء |
| Zone Column / Hinge Board للأقسام العلوية | كانت تُحجب ❌ | **تُرسم وتُقص** ✅ |

### المعادلة الجديدة للظهر

```ts
export function backPanelBottomMm(layout) {           // zones.ts
  const first = layout.bands[0];
  if (!first || !isFloorApplianceZone(first.zone)) return 0;
  return layout.dividerBottomsMm[0] ?? layout.bands.at(-1).bandTopMm;
}
```

- قسم واحد (غسالة فقط) ⇒ لا فاصل ⇒ القيمة = ارتفاع الخزانة ⇒ **طول الظهر = 0** ⇒ لا لوح.
- غسالة + أبواب ⇒ الظهر يبدأ من اللوح الفاصل.

نفس الدالة تُستعمل في `partsEngine` (القص) وفي `assemblyGeometry` (الرسم) ⇒ **لا يمكن أن يختلفا**.

## 5. إصلاح جانبي: استيراد دائري

`zones.ts` يستورد `columns.ts`. وضعتُ الدالة أولاً في `zones.ts` فاستورد `columns.ts` من `zones.ts` ⇒ دورة.
نُقلت `isFloorApplianceZone` إلى **`rules/appliances.ts`** (مكانها الطبيعي، لا دورات)، وتُعاد تصديرها من `zones.ts` ليبقى كل استيراد قديم عاملاً.
