## 16) زاوية L: الأدراج والباب المجاور ⭐ آخر مرحلة
**العيب:** واجهة الدرج في ذراع الزاوية تمتد على كامل العرض في نفس مستوى باب الذراع المجاور المغلق ⇒ لا يخرج
الدرج حتى يُفتح الباب.

**رحلة القرار:**
1. جرّبنا أولاً **قصّ الواجهة** (449 → 430) — رفضتَه لأنه يُضيّع عرض الدرج.
2. ثم **توسيع الذراع** 450 → 469.5 — جميل للدرج، لكنه يدفع طرفها إلى الجارة على الجدار أو خارجه.
3. **القرار النهائي (طلبك):** **ضلفة زاوية ثابتة فقط**، داخل عرض الذراع، وعرضها تحت تحكمك الكامل
   **من سُمك الباب المواجه إلى 50 مم**.

**المنفَّذ:**
- `CORNER.DRAWER_CLEARANCE_MM = 1.5` · `CORNER.FILLER_MAX_MM = 50` (`src/math/constants.ts`).
- `src/math/cornerFiller.ts` (جديد): `autoCornerFillerMm` = سُمك الباب + 1.5 · `cornerFillerWidthMm`
  · `clampCornerFillerMm` (من سُمك الباب إلى 50) · `zoneSlidesOut`.
- الضلفة **واجهة حقيقية** (`kind: 'FILLER'`) في `src/math/zones.ts`: من أسفل الهيكل إلى أعلاه على جهة الزاوية،
  وواجهة الدرج تبدأ **على حافتها** تماماً بلا فاصل ولا تراكب.
- `src/math/partsEngine.ts`: بند `Corner Filler Panel` — لوح الواجهات نفسه، شريط حواف على 4 جوانب، يُقصّ ويُسعَّر.
- `src/math/lCorner.ts`: `withCornerExtension` يُرجع **العرض المصمَّم دائماً** (450)، ويُعيد أي توسيع حفظته نسخة أقدم.
- `src/App.tsx`: حقل **«ضلفة الزاوية الثابتة (مم)»** + زر «تلقائي»، والمعاينة 3D تُظهر الضلفة قبل الحفظ،
  ورسالة بعد الحفظ تذكر العرض والواجهة.

**الأرقام (ذراع 450 · باب 18):**

## 17) زاوية L: الضلفة على كلتا الجهتين ⭐ آخر مرحلة
**الطلب:** «أعطني زر التحكم في إضافة الضلفة في كلتا الجهتين، لأنه يمكن أن تكون الأدراج في الجهة الأخرى،

**المنفَّذ:**
- `src/math/cornerFiller.ts`: نموذج **جهتين** — `FillerSide = 'LEFT' | 'RIGHT'` · `zoneSlidesOut` · `armSlidesOut`
  · `cornerFillerSidesOf` (`undefined` = تلقائي، `[]` = لا شيء) · `cornerFillers(cab, zones, frontTh) → { left, right }`
  · `autoCornerFillerMm` صار واعياً بالجهة: جهة الزاوية = سُمك الباب + 1.5 عند الأدراج، وغيرها = سُمك الباب (للجمال).
- `src/math/zones.ts`: ضلفتان مستقلتان (`FILLER` index 0 = يسرى و1 = يمنى)؛ `drawerSetLeft/Right` و
  `doorSetLeft/Right` تأخذ كل جهة على حدة؛ الأبرونات ولوحات الأجهزة وشرائح الـ`split` مقصوصة عند الضلفتين.
- `src/math/lCorner.ts`: `CornerExtension.cornerFillers = { left, right }` (بدل `cornerFillerMm`)، ونوع الوسيط
  `withCornerExtension` يقبل `cornerFillerSides` ويمرّرها إلى `cornerFillerMm` المحفوظ كأقصى الضلفتين.
- `src/types/flatma.ts`: `cornerFillerSides?: Array<'LEFT' | 'RIGHT'>` بجوار `cornerFillerMm?`.
- `src/App.tsx`: بطاقة الضلفة فيها **تلقائي · بلا ضلفة · اليسرى · اليمنى · الجهتان** + زرّا «ضلفة يسرى/يمنى»،

| | القيمة (مربع 600 · ذراعان 450 · عمق 600 · لوح 18) |

| المقتطع من الداخل | **432 × 432** — قصاصة |
| الطول الممدود | **1446** = 582 + 432 + 432 |
| المساحة / الحافة | **0.868 م²** (كما كانت) / **864 مم** على الواجهتين |
| صفوف القص | **1** بدل 3 (على المربع وحده) |
