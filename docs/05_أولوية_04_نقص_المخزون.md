## 1. ما كان موجوداً فعلاً (تجربة قبل أي تعديل)

| المخزون | هل يُفحص؟ | النتيجة الحقيقية |
|---|---|---|
| **عتاد** (`availableQty`) | جزئياً | يُخصم فوراً عند الإضافة، ويصبح **سالباً** — وهذا مقصود وموثّق: «السالب = عجز مرئي لا خصم صامت». لكن لا رسالة تقول **كم يلزم** |
| **ألواح** (`currentQty`) | ❌ **أبداً** | `currentQty` لا يُنقص في أي مكان. 3 خزائن تحتاج 1.03 لوح ومخزونك لوح واحد ⇒ لا تحذير |
| **رولات الحواف** | ❌ **أبداً** | النوع `EdgeBandRoll` لا يحتوي على «كم بقي» أصلاً، فقط `totalLengthMeters` |

### التجربة التي أثبتت الفراغ

```
خزانة واحدة تحتاج 4 مفصلات · المخزون 2   → issues: []   ← لا كلمة
رول 5 م · نفس الرول للسفل والواجهات = 6.4 م → لا تحذير  ← الرول يُستهلك ضعف حجمه
```

## 2. الحل: وحدة `math/stockCheck.ts`

```ts
checkStock(cabinets, woods, hardware, rolls)             → StockShortage[]
checkStockFromPricing(pricing, woods, hardware, rolls)   → StockShortage[]   // يُعيد استعمال تسعير BOM
demandOf(pricing)                                        → { sheets, band, hardware }
```

الوحدة **لا تُسعّر شيئاً**: تقرأ نتيجة `priceCabinet` — نفس مصدر قائمة القص والتكلفة — وتجمع الطلب ثم تقارنه بالمخزون.
لذلك يستحيل أن يختلف تقرير العجز عن قائمة القص.

### القواعد الثلاث (كل واحدة لها سبب)

| النوع | كيف تُحسب الحاجة | كيف تُقارن |
|---|---|---|
| **SHEET** | مجموع `p.sheets` لكل مادة (يشمل `PANEL.WASTE_FACTOR` أصلاً) | `currentQty` للمادة نفسها |
| **EDGE_BAND** | مجموع الأمتار **مجمّعة بالرول** — نفس الرول للسفل والواجهة = استهلاك واحد | `remainingLengthMeters ?? totalLengthMeters` |
| **HARDWARE** | `h.quantity` من BOM | `availableQty` **بعد** الخصم: `المتوفر = المخزون الحالي + ما أخذه المشروع` |

**لماذا قاعدة العتاد مختلفة؟** لأن السياق يخصم العتاد فوراً عند تثبيت الخزانة (`stockDelta`). لو قارنّا «المطلوب» بـ«المتوفر» مباشرة لَحسبنا نفس القطع مرتين.
الصيغة `available = availableQty + required` تُرجع «ما كان في الورشة قبل هذا المشروع» ⇒ الفرق يساوي تماماً العجز السالب، بلا ازدواج.

## 3. البيانات: الرول صار يعرف ما بقي

```ts
export interface EdgeBandRoll {
  totalLengthMeters: number;
  /** ما بقي على الرول. غائب = الرول كامل (كل البيانات القديمة تعمل كما هي). */
  remainingLengthMeters?: number;
  rollPriceDA: number;
}
```

- السعر لكل متر يبقى على `totalLengthMeters` (ثمن الرول ÷ طوله) — لم يتغيّر شيء في الفاتورة.
- `InventoryManager` صار يعرض `المتبقي / الكلي` ويُلوّن الأحمر عند 0.

## 6. الاختبارات العشرة

| # | يحمي من |
|---|---|
| 1 | لوح ناقص بلا تحذير (المطلوب/المتوفر/الناقص بالأرقام + صيغة الرسالة) |
